# OsintGram

**Telegram client** for Android with:

- Full **Ghost Mode** (hide online, typing, read receipts, story views)
- **Saved deleted messages** — you still see them and can reply
- **Edit history** — original + new version of edited messages
- Enhanced anonymity settings
- Planned built-in OSINT tools (later)

Based on [AyuGram4A](https://github.com/AyuGram/AyuGram4A) (exteraGram + Telegraher patches).

## Features we keep

- Full flexible Ghost Mode
- Messages history (deleted messages are saved persistently)
- Customizable marks for edited/deleted messages
- Message filters
- Local Premium features

## What we change for OsintGram

- No plugin system
- Rebrand to **OsintGram**
- Future OSINT modules

## Important

This is an unofficial client and violates Telegram Developer ToS.  
You must use your own API credentials from https://my.telegram.org.  
Use at your own risk.
